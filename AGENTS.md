# Codex Project Instructions

## Technology Stack
HTML, CSS, and JavaScript.

## Coding Conventions
- Use clear and descriptive names.
- Keep code readable and organized.
- Avoid unnecessary dependencies.
- Follow consistent formatting.

## Testing
- Test changes before considering tasks complete.
- Report any tests that could not be performed.
- Do not claim unimplemented features work.

## Git
- Use Conventional Commits.
- Do not commit or push without permission.

## Documentation
- Keep README.md accurate and updated.
- Never invent completed features.

## Change Management

- Inspect existing files before editing.
- Make focused, minimal changes.
- Explain important changes after completing a task.
- Ask before adding dependencies.
- Never expose API keys, passwords, or secrets.
- Do not claim tests passed unless they were run successfully.
